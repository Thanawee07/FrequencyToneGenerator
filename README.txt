Frequency Tone Generator 1.0
- Android 6.0+ (API 23), target Android 15
- Frequency 100-500 Hz
- Duration 15-180 seconds
- Sine-wave PCM audio through Android STREAM_MUSIC
- Bluetooth button opens Android Bluetooth settings; select/route audio to your Bluetooth speaker/headphones.
Build with Android Studio: open this folder, then Build > Build APK(s).
